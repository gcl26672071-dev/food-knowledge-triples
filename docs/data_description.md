# 数据说明（Data Description）

## 数据集名称

Food Knowledge Triple Dataset / 食物知识三元组数据集

## 目标

用于表示食物名称及其外形、口感、味道等知识关系，可服务于知识图谱、自然语言处理、语义建模、隐写相关实验或其他研究任务。

## 三元组结构

`(subject, relation, object)`

例如：

- `(食物, 名称, 佛跳墙)`
- `(佛跳墙, 味道, 腥味)`

## 关系集合

- `名称`
- `外形`
- `口感`
- `味道`

## 推荐数据版本

`data/processed/food_triples.csv`：2032 条完整且精确去重的三元组。

## 原始记录与可追溯性

原始文件保存在 `data/raw/food_triples_original.csv`。清洗时没有覆盖原文件；所有不能安全自动处理的缺失记录均单独保存在 `data_review/`。

5. 是否经过人工标注及标注规则；
6. 如涉及第三方数据，必须保留必要署名和许可说明。

## 已知限制

- 当前版本只进行结构性清洗，不保证全部三元组在语义层面完全正确。
- 未对同义词、近义词和表达变体进行实体标准化。
- 未对不完整记录进行自动语义补全。
- 重复记录含义不明，因此同时提供含重复版本和精确去重版本。
